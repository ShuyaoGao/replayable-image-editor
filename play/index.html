    这是什么

    一个能用的网页图像编辑器。和普通编辑器不同的是：你的每一次操作都被记成一行 JSON， 整段日志可以导出、导入，并且按日志回放能逐像素还原画面。这样的“操作序列”可以当作训练数据， 让模型学习“人是怎么一步步修图的”。

    三个模式（页面顶部）

    • 看回放：自动播放一段示例日志，每一步都有说明；可以暂停、单步、调速度。
    • 我来修图：自己动手，右栏实时显示你的操作被记成什么、变成哪些 token。
    • 练习：按任务清单一步步做，完成一项自动打勾。

    右栏

    上面：当前这一步的 JSON 与 token；下面三个标签：完整日志、回放校验与量化（PSNR）、滤镜的像素原理。

    怎么操作

    • 左侧工具栏选工具，鼠标停在按钮上会出现动画演示。
    • 滚轮缩放；按住空格拖动（或用 ✋）平移画布。
    • 快捷键：V 移动 · M 矩形选区 · B 画笔 · E 橡皮 · G 油漆桶 · U 形状 · T 文字 · I 吸管 · C 裁剪
    • Ctrl+Z 撤销 · Ctrl+Y 重做 · Ctrl+D 取消选区 · [ ] 调画笔大小 · H 打开本说明

    手机 / 平板：上面是画布，下面是工具条、选项条、图层条和「撤销 / 重做 / 导出 / 看日志」四个大按钮； 整页不用上下滚动。右上角 ☰ 里有导入 / 导出日志、操作说明和退出。

    两组预设档位

    • 回放速度：逐条讲解 / 正常 / 快速 / 瞬间。
    • token 量化：原始 / 细 1024 / 中 256 / 粗 64 —— 档数越少词表越小，回放误差越大，用 PSNR 衡量。
